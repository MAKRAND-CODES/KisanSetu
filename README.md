# 🌾 KisanSetu

## Smart Agriculture Support Platform

KisanSetu is a full-stack MERN-based agriculture platform built to empower farmers with digital tools for farm management, crop advisory, government scheme awareness, crop insurance, compensation complaints, satellite crop monitoring, real-time weather intelligence, and daily live mandi price tracking.

The platform supports multiple user roles including Farmers, Officers, and Administrators, creating a complete agricultural support ecosystem.

This is My personal Initiative to build KisanSetu as an Agri based Platform to support more and more farmers across India. Many features are awaiting and are on the way but the one with latest contains the following one.

# 📦 Installation

## Clone Repository

```bash
git clone YOUR_REPOSITORY_URL
```

## Backend Setup

```bash
cd backend

npm install

npm run dev
```

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
